# 10.1 Viết lại readme

## Mục tiêu

Readme bản cuối ngắn, đúng code, có link triển khai và cách chạy.

## Đã làm

* Viết lại `readme.md` từ 500 dòng còn khoảng 170 dòng: giới thiệu, link, nhóm, chức năng, công nghệ, cây thư mục rút gọn, cách chạy, kiểm thử, tài liệu API.
* Bỏ emoji, bảng, link markdown và phần đã có ở tài liệu khác (UML, danh sách API, kế hoạch).

## File thay đổi

* `readme.md`

## Kiểm thử

* Đối chiếu lệnh với `package.json`, biến môi trường với code. Không chạy lại từ đầu trên máy mới.

## Lưu ý

* Còn thiếu link video, thêm sau khi quay.
