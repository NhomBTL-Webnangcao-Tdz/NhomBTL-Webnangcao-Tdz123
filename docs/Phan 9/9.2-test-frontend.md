# 9.2 Test component frontend

## Mục tiêu

Có test cho form, guard, xử lý phiên ở frontend [Đề 7e].

## Đã làm

* `api/client.test.js`: gửi token, xử lý 401, 403, 429, lỗi dạng mảng, mất kết nối.
* `components/guards/RoleBasedRoute.test.js`: đang tải, chưa đăng nhập, sai vai trò, đúng vai trò.
* `pages/auth/AuthForms.test.js`: form đăng nhập, đăng ký; chuyển trang theo vai trò, lỗi backend, chặn gửi 2 lần, chống XSS.
* `context/AuthContext.test.js`: khôi phục phiên, token hết hạn, máy chủ lỗi, đăng nhập, đăng xuất.
* Không sửa code chạy thật, chỉ thêm test.
* Vai trò: Tân soạn bản đầu, Sơn tích hợp, kiểm thử.
