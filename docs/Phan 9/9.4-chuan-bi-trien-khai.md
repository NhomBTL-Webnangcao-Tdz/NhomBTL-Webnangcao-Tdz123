# 9.4 Chuẩn bị triển khai

## Mục tiêu

Sẵn sàng đưa lên Vercel, Render để có link demo [Đề 8].

## Đã làm

* Thêm `quan-ly-ktx/backend/render.yaml` và hướng dẫn `docs/trien-khai.md`.
* Xác minh NestJS 12 cần Node từ 20, ghi vào readme (phần 11).

## File thay đổi

* `quan-ly-ktx/backend/render.yaml`, `docs/trien-khai.md`, `readme.md`

## Kiểm thử

* Mô phỏng Render trên máy: lấy bản sạch từ git, cài với `NODE_ENV=production`, build, chạy với `DB_SYNCHRONIZE=false` và DB Aiven. Đăng nhập, `/api-docs` đạt; CORS chỉ nhận đúng `FRONTEND_URL`.
* Frontend `CI=true npm run build` đạt, Vercel coi cảnh báo là lỗi nên cần kiểm này.
* Chưa triển khai thật, cần Tân tạo tài khoản.

## Lưu ý

* Dùng `--no-package-lock` vì lock file backend đang lệch. Nam sửa lock xong thì có thể bỏ.
