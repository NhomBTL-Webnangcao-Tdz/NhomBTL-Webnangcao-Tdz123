# 6.12 (phần 1) Trang chủ dùng react-bootstrap

Ngày: 01/11/2026. Đề 5b. Theo quyết định 2.16: giữ thiết kế, nội dung trang chủ của Nam (`pages/landing`).

## Mục tiêu

Trang chủ dựng bằng component `react-bootstrap`, giao diện giữ như cũ.

## Đã làm

* `index.js`: import `bootstrap/dist/css/bootstrap.min.css` trước `index.css`.
* Header: `Navbar`, `Navbar.Brand`, `Navbar.Toggle`, `Navbar.Collapse`, `Nav`, `Nav.Link`, `Button`. Thêm menu ☰ dưới 992px (trước đây menu bị ẩn hẳn trên điện thoại).
* Thân trang: `Container`, `Row`, `Col`, `Card`, `Card.Title`, `Card.Text`, `Stack`, `Button`; footer: `Container`, `Row`, `Col`, `Nav`.
* CSS: bỏ grid tự viết, dùng gutter của `Row`; khai báo màu khi bấm cho nút; nút chuyển trang có `role="link"`.
* `index.css`: giữ tiêu đề đậm 700 (Bootstrap mặc định 500).

## File thay đổi

* `src/index.js`, `src/index.css`
* `src/pages/landing/Landing{Page,Header,Navigation,Footer}.{js,css}`

## Kiểm thử

* Unit test 25/25; `CI=true npm run build` thành công, không cảnh báo.
* Chụp trước/sau ở 1280px và 375px: trang chủ giống bản cũ; 375px không cuộn ngang; menu ☰ mở 6 link, bấm chuyển đúng mục.
* So điểm ảnh 8 trang quản lý và sinh viên trước/sau khi thêm Bootstrap (backend giả): chỉ lệch 1–3px theo chiều dọc do `line-height` 1.5 của Bootstrap, bố cục không đổi.

## Lưu ý

* Các trang sau đăng nhập vẫn dùng CSS tự viết; chuyển tiếp sang react-bootstrap là phần 2 của 6.12 (cần chốt phạm vi ở 2.10).
* Logo nguyên tử của trang chủ giống logo React; đề xuất Nam đổi sang logo riêng (xem `docs/luat-dao-duc.md`).
* Đã dừng server thử, xóa ảnh chụp và `.claude/launch.json` tạm trong repo.
