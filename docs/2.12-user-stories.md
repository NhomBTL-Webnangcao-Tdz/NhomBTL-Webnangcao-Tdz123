# 2.12 Nháp user stories

Ngày: 26/10/2026 · Dựa trên commit `85e32b4`.

## Mục tiêu
Có bản nháp user stories cho Đề 1: tối thiểu 12 câu, đúng định dạng "Là <vai trò>, tôi muốn <hành động>.". Mỗi câu gắn với API và màn hình, để các câu sau của đề (2b, 3b, 7b, 7d) tham chiếu.

## Đã làm
- Viết `docs/user-stories.md` gồm 24 câu, mã US-01 đến US-24, chia theo vai trò:
  - khách / người dùng chung: 6 câu;
  - sinh viên: 7 câu;
  - cán bộ quản lý: 8 câu;
  - quản trị viên: 3 câu.
- Mỗi câu ghi API backend, màn hình (hash route) và hiện trạng code. Hiện trạng: 18 câu Có, 3 câu Một phần (US-04, 16, 20), 3 câu Chưa (US-05, 21, 23). Câu chưa đủ có ghi mục checklist cần làm.
- Nguồn: vai trò và luồng L1–L6 trong `docs/ke-hoach.md`, cùng các controller, route frontend đang có trên `main`.
- Thêm link tới file trong `docs/readme.md`, `.claude/CLAUDE.md`, cây thư mục của `readme.md` và `checklist.md`. Đánh dấu 2.12 là `[~]`.

## Kiểm thử
- Script kiểm tra: đủ 24 câu, không trùng mã. Cả 24 câu khớp mẫu `Là <khách|người dùng|sinh viên|cán bộ quản lý|quản trị viên>, tôi muốn … để ….`
- Đối chiếu từng API trong bảng với decorator `@Controller`/`@Get`/`@Post`/… trong backend, và từng màn hình với `App.js` (`STUDENT_PAGES`, `switch (currentPage)`).
- Chưa kiểm thử các chức năng trên app thật. Cột "Code" chỉ dựa trên việc đọc code.

## Lưu ý
- **Bản nháp, chờ nhóm duyệt.** Câu chữ và việc giữ hay bỏ các câu "Chưa" là quyết định của nhóm.
- Phát hiện khi viết: `PUT /utility-bill/tariff` đang cho cả `MANAGER` sửa đơn giá, còn `docs/ke-hoach.md` đề xuất chỉ `ADMIN`. Trang `#settings` ở frontend chỉ cho `ADMIN`. Cần backend quyết (ghi ở US-22).
- Bảng route trong `readme.md` mục 7.3 đã cũ: vẫn còn `#students`, thiếu `#requests`, `#my-contact`. Để sửa ở lần rà readme sau, không sửa trong mục này.
