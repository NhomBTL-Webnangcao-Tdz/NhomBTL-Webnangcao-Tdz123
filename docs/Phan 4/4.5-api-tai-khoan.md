# 4.5 API tài khoản cho ADMIN

## Mục tiêu

ADMIN xem danh sách tài khoản, tạo cán bộ, đổi vai trò.

## Đã làm

* Thêm `GET /users`, `POST /users` (luôn tạo MANAGER), `PATCH /users/:id/role`, chỉ ADMIN.
* Không cho tự đổi vai trò của mình, không cho hạ ADMIN cuối cùng.
* Tách phần kiểm tra trùng và băm mật khẩu trong `AuthService` để đăng ký và tạo cán bộ dùng chung. Đăng ký công khai vẫn luôn là STUDENT.
* Bổ sung 3 endpoint vào Swagger.

## File thay đổi

* `quan-ly-ktx/backend/src/auth/users.controller.ts`, `dto/update-user-role.dto.ts`, `entities/users.service.role.spec.ts` (mới)
* `quan-ly-ktx/backend/src/auth/auth.service.ts`, `auth.module.ts`, `entities/users.service.ts`
* `quan-ly-ktx/backend/src/swagger.ts`

## Kiểm thử

## Lưu ý

* Vai trò nằm trong JWT nên người bị đổi vai trò vẫn giữ quyền cũ tới khi token hết hạn, tối đa 1 giờ.
