# 4.10 Tài liệu hóa API

## Mục tiêu

Tài liệu đủ endpoint, quyền, ví dụ request/response, mã lỗi [Đề 4b]. Tạm hiểu là Swagger/OpenAPI, chờ 2.15.

## Đã làm

* Thêm `@nestjs/swagger`, mở tại `/api-docs`; bật plugin trong `nest-cli.json` để tự lấy schema từ DTO.
* Gom mô tả, quyền, ví dụ, mã lỗi vào `src/swagger.ts`, không sửa controller để tránh conflict với Nam.
* Route mới chưa có mô tả sẽ được cảnh báo khi khởi động.

## File thay đổi

* `quan-ly-ktx/backend/src/swagger.ts`, `src/main.ts`
* `quan-ly-ktx/backend/nest-cli.json`, `package.json`
* `readme.md`

## Kiểm thử

* `npm test`: 70/70.
* Chạy backend thật: `/api-docs` trả 200, đủ 43 endpoint, mọi endpoint có quyền và không route nào thiếu mô tả.

## Lưu ý

* Cài bằng `--no-package-lock` vì lock file do Nam sửa, nên `package-lock.json` chưa có `@nestjs/swagger`. Nam chạy `npm install` rồi commit lock file sau khi pull.
* Quyền trong `swagger.ts` ghi tay, phải giữ khớp `@Roles`. Nam thêm Payment, reports thì bổ sung vào file này.
* `PUT /utility-bill/tariff` đang cho cả MANAGER, trong khi 4.6 ghi chỉ ADMIN và giao diện cũng cho MANAGER sửa. Tài liệu ghi theo code, cần chốt ở 4.6.
* 4.9 (`helmet`) có thể chặn script của Swagger UI, người làm 4.9 cần thử lại `/api-docs`.
