# 4.8 Phân trang, tìm kiếm, lọc

## Mục tiêu

Danh sách hỗ trợ `?page=&limit=&q=&building=&status=`.

## Đã làm

* Thêm `ListQueryDto`, `RoomListQueryDto`, `BillListQueryDto`. `limit` tối đa 100.
* `GET /rooms`: `q`, `building`, `status` (`available`, `full`, `empty`).
* `GET /student`: `q` theo mã, tên, email, SĐT.
* `GET /utility-bill`: `q`, `month`, `year`, `building`, `status` (`paid`, `unpaid`).
* Có `page` thì trả `{ items, total, page, limit }`; không có thì trả mảng như cũ nên các trang hiện tại không phải sửa.

## File thay đổi

* `quan-ly-ktx/backend/src/common/list-query.dto.ts` và spec
* `quan-ly-ktx/backend/src/modules/room/`, `student/`, `utility-bill/`: controller, service, DTO
* `quan-ly-ktx/backend/src/swagger.ts`

## Kiểm thử

* `npm test`: 92/92.
* API thật trên dữ liệu seed, 22 ca đạt: phân trang, lọc tòa, lọc trạng thái, kỳ, `%` không khớp tất cả, chuỗi SQL injection trong `q` không gây lỗi, `limit` quá lớn và tham số lạ trả 400.

## Lưu ý

* Chưa làm cho `GET /contract` vì Nam đang sửa module này.
* Hóa đơn tìm theo tên sinh viên chỉ trả phần của sinh viên khớp trong `shares`, không đủ cả phòng.
* Giao diện vẫn lọc phía client vì dữ liệu nhỏ; API này sẵn sàng khi dữ liệu lớn.
