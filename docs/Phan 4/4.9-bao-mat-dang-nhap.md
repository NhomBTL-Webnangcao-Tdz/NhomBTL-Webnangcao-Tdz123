# 4.9 Bảo mật đăng nhập

## Mục tiêu

Chặn dò mật khẩu và thêm header bảo mật cho backend [Đề 3d, 4c].

## Đã làm

* Thêm `LoginAttemptService`: đếm lần sai theo IP và tên đăng nhập, sai 5 lần thì khóa 15 phút, trả 429. Đăng nhập đúng thì xóa bộ đếm.
* Tên đăng nhập không tồn tại cũng bị đếm, nên việc khóa không lộ tài khoản nào có thật.
* Bật `helmet` trong `main.ts`; nới CSP cho script, style nội tuyến để Swagger UI chạy.
* Đặt `trust proxy` để lấy đúng IP người dùng khi chạy sau proxy của Render.
* Bổ sung 429 vào exception filter, Swagger; cập nhật `docs/luat-dao-duc.md`.
* Vai trò: Tân soạn bản đầu, Sơn tích hợp, kiểm thử.

## Kiểm thử

* Backend test: 130/130 (thêm 8). `npm run build` đạt.
* Chạy backend thật: 5 lần sai trả 401, lần 6 và 7 trả 429. Có đủ header CSP, HSTS, `X-Content-Type-Options`, `X-Frame-Options`.
* CORS từ `localhost:3000` vẫn trả 204. Swagger `/api-docs` hiện đủ, không lỗi console.
* Chưa kiểm trên bản Render: IP lấy qua proxy.

## Lưu ý

* Bộ đếm nằm trong bộ nhớ: backend khởi động lại thì về 0, chạy nhiều máy chủ phải chuyển sang Redis.
* Nếu Render có nhiều hơn 1 proxy, IP đọc được là IP proxy. Khi đó khóa theo tên đăng nhập cho mọi người, vẫn chặn được dò mật khẩu.
* Backend chưa sửa lock file (việc của Nam), nên `helmet` chỉ thêm vào `package.json`. Cài bằng `npm install --no-package-lock`.
