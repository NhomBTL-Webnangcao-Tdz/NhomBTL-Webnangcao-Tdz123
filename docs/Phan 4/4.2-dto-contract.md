# 4.2 (phần 1) DTO cho Contract

## Mục tiêu

Kiểm tra body của `POST/PUT /contract`, chặn gán trường lạ [Đề 3d, 4c]. Làm trước để Nam làm tiếp 5.1, 5.2.

## Đã làm

* Thêm `CreateContractDto`, `UpdateContractDto`. Giữ nguyên dạng body frontend đang gửi (`student: { sid }`, `room: { id } | null`).
* Kiểm tra: ngày đúng định dạng, ngày kết thúc không trước ngày bắt đầu, tiền cọc từ 0 và vừa cột `decimal(10,2)`.
* `:id` dùng `ParseIntPipe`, id không phải số trả 400.

## File thay đổi

* `quan-ly-ktx/backend/src/modules/contract/dto/` (3 file mới, gồm spec)
* `quan-ly-ktx/backend/src/modules/contract/contract.controller.ts`
* `quan-ly-ktx/backend/src/modules/contract/contract.service.ts`

## Kiểm thử

* `npm test`: 41/41 (thêm 14 test DTO).
* Chạy backend thật trên Aiven của Tân, gọi API: không token 401; thiếu SV, sai ngày, cọc âm, trường lạ, id sai 400; tạo, chưa xếp phòng, thanh lý, gia hạn, xóa đều đúng. Ca "đăng nhập" báo lỗi trong script là do script mong đợi nhầm 201, API trả 200 là đúng.
* Đã xóa hết dữ liệu `test-`.
