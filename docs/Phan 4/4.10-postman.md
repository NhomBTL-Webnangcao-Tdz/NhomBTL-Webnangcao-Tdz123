# 4.10 (phần 2) Postman collection

## Mục tiêu

Tài liệu API theo công cụ cô dùng trên lớp (2.15), giữ thêm Swagger [Đề 4b].

## Đã làm

* Thêm `docs/postman/ktx-care.postman_collection.json`: 46 request chia theo nhóm, có ví dụ body, quyền, biến `baseUrl`, `username`, `password`, `token`.
* Request đăng nhập tự lưu token, các request sau dùng lại.
* Thêm `scripts/export-postman.js` và lệnh `npm run postman:export` để xuất lại từ Swagger.

## File thay đổi

* `docs/postman/ktx-care.postman_collection.json`
* `quan-ly-ktx/backend/scripts/export-postman.js`, `package.json`
* `readme.md`

## Kiểm thử

* Chạy bằng newman trên backend thật: đăng nhập và 4 request chỉ đọc đều 200, token tự lưu đúng.
* Collection không chứa mật khẩu thật. Chưa mở thử trong ứng dụng Postman, chưa chạy các request ghi dữ liệu.

## Lưu ý

* Nam thêm Payment, reports thì chạy lại lệnh xuất. Nhập collection vào Thunder Client cũng được.
