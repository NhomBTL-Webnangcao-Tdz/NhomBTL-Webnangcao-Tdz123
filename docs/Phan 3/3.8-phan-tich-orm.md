# 3.8 Phân tích ORM

## Mục tiêu

Viết phân tích ORM cho báo cáo, kèm SQL thật do TypeORM sinh [Đề 6b].

## Đã làm

* Viết `docs/phan-tich-orm.md`: DataSource, entity ứng với bảng, quan hệ ứng với khóa ngoại, repository, SQL, nhận xét.
* Lấy SQL bằng `getQueryAndParameters()` từ code chạy thật, không ghi dữ liệu. Khóa ngoại lấy từ `information_schema` của DB.

## File thay đổi

* `docs/phan-tich-orm.md`

## Kiểm thử

* Đối chiếu 8 khóa ngoại với DB Aiven của Tân.

## Lưu ý

* Nam đổi entity thì cập nhật lại file này và `database/init.sql`.
