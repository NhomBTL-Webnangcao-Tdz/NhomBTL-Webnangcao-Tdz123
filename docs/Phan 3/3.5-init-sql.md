# 3.5 Tạo bảng cho production

## Mục tiêu

Có sẵn script tạo bảng cho môi trường production, nơi `DB_SYNCHRONIZE` tắt mặc định.

## Đã làm

* Chạy backend trên Aiven của Tân để TypeORM tạo 11 bảng, rồi xuất `SHOW CREATE TABLE` thành `database/init.sql`. Chọn cách này thay migration vì ít thay đổi nhất sát hạn.
* File `database/init.sql` mà readme nhắc tới trước đó không còn trong repo, nay tạo lại đủ bảng.
* Cập nhật readme.

## File thay đổi

* `quan-ly-ktx/backend/database/init.sql`
* `readme.md`

## Kiểm thử

* Chạy `init.sql` trên DB tạm `test_init_sql_tmp`: đủ 11 bảng, 8 khóa ngoại, bằng DB gốc. Đã xóa DB tạm.

## Lưu ý

* Đổi entity thì phải xuất lại file này. Nếu Nam đổi entity ở 4.3, 5.x thì cần cập nhật.
