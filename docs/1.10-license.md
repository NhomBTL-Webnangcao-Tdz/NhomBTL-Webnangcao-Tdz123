# 1.10 LICENSE

Ngày: 01/11/2026. Đề 3c.

## Mục tiêu

Repo có file LICENSE kèm thông báo bản quyền.

## Đã làm

* Thêm `LICENSE` (MIT, "Copyright (c) 2026 Nhóm BTL Web nâng cao N02 - Đại học Phenikaa", tên 3 thành viên) ở gốc repo và `quan-ly-ktx/frontend/`.
* `quan-ly-ktx/frontend/package.json` (và `package-lock.json`): thêm `"license": "MIT"`.

## File thay đổi

* `LICENSE`, `quan-ly-ktx/frontend/LICENSE` (mới)
* `quan-ly-ktx/frontend/package.json`, `quan-ly-ktx/frontend/package-lock.json`

## Kiểm thử

* `npm ls --depth=0` không lỗi; `require('./package.json').license` trả `MIT`.

## Lưu ý

* Tạm chọn MIT theo đề xuất trong checklist; nhóm muốn loại khác thì chỉ cần thay nội dung file.
* Đề xuất cho backend (Nam): `quan-ly-ktx/backend/package.json` đang ghi `"license": "UNLICENSED"`, nên đổi thành `MIT` cho khớp. Chưa sửa vì là phần backend.
