# 1.9 Thêm frontend/.env.example

Ngày: 26/10/2026. Dựa trên commit `85e32b4`.

## Mục tiêu

Có file mẫu biến môi trường cho frontend, để thành viên mới biết frontend đọc những biến nào và tự tạo `.env`.

## Đã làm

* Tìm mọi chỗ dùng `process.env` trong `quan-ly-ktx/frontend/src`. Có 3 biến tự đặt: `REACT_APP_API_URL` (`api/client.js`), `REACT_APP_MANAGER_EMAIL` và `REACT_APP_MANAGER_PHONE` (`pages/student/ContactPage.js`). `PUBLIC_URL` do CRA tự đặt nên không đưa vào file mẫu.
* Tạo `quan-ly-ktx/frontend/.env.example` có đủ 3 biến, chú thích ý nghĩa và giá trị mặc định, kèm cảnh báo: biến `REACT_APP_*` bị nhúng vào bundle nên không được đặt bí mật (liên quan Đề 3d).
* `readme.md` mục 7.3 bước 3: thay hướng dẫn tự tạo `.env` một biến bằng lệnh `cp .env.example .env`, thêm danh sách 3 biến và cảnh báo trên.

* `git check-ignore`: `.env.example` không bị bỏ qua; `quan-ly-ktx/frontend/.env` bị bỏ qua (quy tắc `.env` ở `.gitignore` gốc).
* Chép `.env.example` thành `.env`, điền giá trị thử dễ nhận ra (`http://test-1-9.local:5999/`, `test-1-9@example.com`, `0900-000-199`), chạy `npm run build`: build thành công, cả 3 giá trị có trong `build/static/js/main.*.js`. Dấu `/` cuối URL được `client.js` cắt bỏ.
* Xóa `.env` rồi build lại: bundle quay về giá trị mặc định `http://localhost:5001`.
